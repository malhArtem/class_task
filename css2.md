# Задания: margin, padding, div (без flex)


## 1. Три квадрата

**Задача:**  
Создай три `div` 100×100 px (красный, зелёный, синий) друг под другом.

```html
<div class="red"></div>
<div class="green"></div>
<div class="blue"></div>
```

```css
div { width: 100px; height: 100px; }
.red   { background: red; }
.green { background: green; }
.blue  { background: blue; }
```

**Проверь себя:**
- Почему блоки в столбик, а не в ряд?
- Что будет, если убрать `height`?

---

## 2. Padding vs Margin

**Задача:**  
Красному квадрату добавь `padding: 20px`, зелёному — `margin: 20px`. В красный положи текст.

**Проверь себя:**
- У какого блока выросла цветная область?
- У какого выросло расстояние до соседей?
- Что закрашивает фон — padding или margin?

## 3. Рамка и outline

**Задача:**  
Синему квадрату добавь `border: 5px solid black` и `outline: 2px dashed red`.

**Проверь себя:**
- В каком порядке идут слои: content → ? → ? → ?
- Где проходит outline относительно border и margin?
- Фон заходит под рамку?

## 4. Четыре стороны

**Задача:**  
Задай блоку:
```css
padding: 10px 20px 30px 40px;
margin:  5px 10px 15px 20px;
```
Определи, где какая сторона. Сократи до двух значений, потом до одного.

**Проверь себя:**
- В каком порядке идут 4 значения?
- Чему равен `padding-left` при `padding: 10px 20px`?

**Проверь себя:**

## 6. Три блока в ряд

**Задача:**  
Контейнер 800 px, `margin: 0 auto`, серый фон. Внутри три блока по 200×100 px. Расположи их **в ряд** через `display: inline-block`.

**Проверь себя:**
- Почему между блоками появились пробелы?
- Как их убрать? (три способа: убрать переносы в HTML, `font-size: 0` у родителя, `margin-left: -4px`)

---

## 7. Две колонки через float

**Задача:**  
Родитель 600 px. Внутри два блока `width: 50%; padding: 20px; border: 2px solid; float: left;`. Заставь их встать в ряд **и** поместиться в родителя.

**Подсказка:**  
Проблема в том, что 50% + padding + border > 50%. Решение — `box-sizing: border-box`. И не забудь `overflow: hidden` у родителя.

**Проверь себя:**
- Сколько реально занимает одна колонка без `border-box`?
- Что делает `overflow: hidden` у родителя?
- Что делает `box-sizing: border-box`?

## 10. Мини-проект: меню

**Задача:**  
Горизонтальное меню из 4 ссылок: Главная, О нас, Услуги, Контакты.
- каждая `<a>` — `display: inline-block; padding: 15px 25px`
- между ними `margin: 0 5px`
- тёмный фон, при наведении меняется цвет

**Проверь себя:**
- Почему ссылкам нужен `display: inline-block`?
- Как убрать пробелы между ссылками?
- Как убрать подчёркивание?
