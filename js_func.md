# Функции в JavaScript

## Кусочек 1. Что такое функция и зачем она

**Теория.** Функция — это **переиспользуемый кусок кода** с именем. Один раз описали — вызываем сколько нужно раз. Это спасает от копипасты и делает код понятным.

Аналогия: рецепт. Написали один раз — готовим по нему много раз.

```js
function greet() {
  console.log("Привет!");
}

greet();   // Привет!
greet();   // Привет!
```

Правила:
- `function` — ключевое слово.
- `greet` — имя функции.
- `{ ... }` — **тело**: что делать.
- `greet()` — **вызов**. Без скобок функция не выполняется, а просто «лежит».

⚠️ `console.log(greet);` (без скобок) выведет саму функцию, а не результат. Не путай.

**Задания:**
1. Создай функцию `sayHello`, которая выводит в консоль `"Привет, мир!"`. Вызови её **два раза**.
2. Создай функцию `showDate`, которая выводит текущий год (`2026`). Вызови.
3. **Проверь ошибку:** напиши `console.log(sayHello);` (без скобок). Что вывелось? Чем это отличается от `sayHello();`?

## Кусочек 2. Параметры и аргументы

**Теория.** Функция может **принимать данные** — параметры. При вызове ты передаёшь **аргументы** — конкретные значения.

```js
function greet(name) {           // name — параметр
  console.log(`Привет, ${name}!`);
}

greet("Аня");   // Привет, Аня!  — "Аня" — аргумент
greet("Иван");  // Привет, Иван!
```

Параметров может быть несколько:
```js
function sum(a, b) {
  console.log(a + b);
}

sum(2, 3);   // 5
sum(10, 7);  // 17
```

Важно: параметры — это **локальные** переменные, они живут только внутри функции.

**Задания:**
1. Создай функцию `greet(name)`, которая выводит `Привет, <name>!`. Вызови с `"Аня"`, `"Иван"`, `"Мария"`.
2. Создай `sum(a, b)`, которая выводит сумму. Проверь на `(2, 3)`, `(10, 7)`, `(-5, 5)`.
3. Создай `introduce(name, city)`, которая выводит: `Меня зовут <name>, я из <city>.` Вызови с разными значениями.

## Кусочек 3. `return` — функция возвращает результат

**Теория.** До сих пор функция только **печатала**. Но чаще она должна **вернуть значение**, чтобы мы могли его использовать: сохранить, передать дальше, посчитать.

```js
function sum(a, b) {
  return a + b;
}

const result = sum(2, 3);
console.log(result);          // 5
console.log(sum(10, 7) * 2);  // 34
```

Ключевые моменты про `return`:
- **Прерывает** функцию — код после `return` не выполняется.
- Если `return` нет — функция возвращает `undefined`.
- `console.log` **печатает** в консоль, а `return` **отдаёт значение** в код. Это **разные вещи**.

```js
function a() { console.log("я печатаю"); }
function b() { return "я возвращаю"; }

const x = a();   // x === undefined (но в консоли увидишь "я печатаю")
const y = b();   // y === "я возвращаю"
```

**Задания:**
1. Перепиши свою функцию `sum(a, b)` из кусочка 2 так, чтобы она **возвращала** сумму, а не печатала. Вызови и выведи результат.
2. Создай `square(n)`, которая возвращает `n * n`. Выведи `square(5)`.
3. Создай `isAdult(age)`, которая **возвращает** `true` или `false`. Проверь в `if`.
4. **Вопрос на подумать:** что выведет и почему?
   ```js
   function test() {
     return 1;
     console.log("это не выполнится");
   }
   console.log(test());
   ```

## Кусочек 4. Стрелочные функции (короткий синтаксис)

**Теория.** Современный и очень распространённый способ записать функцию короче.

```js
// Обычная функция
function sum(a, b) { return a + b; }

// Стрелочная — то же самое
const sum = (a, b) => a + b;
```

Разные варианты записи:
```js
const greet = (name) => { return `Привет, ${name}!`; };   // полный вид
const greet = (name) => `Привет, ${name}!`;               // return неявный
const square = n => n * n;                                // один параметр — без скобок
const sayHi = () => console.log("Привет");                // без параметров — пустые ()
```

Правило: если в теле **одно выражение** — `return` не пишем, скобки `{ }` тоже. Если тело большое или несколько строк — пишем `{ ... return ...; }` явно.

**Задания:**
1. Перепиши `sum(a, b)` из кусочка 3 в стрелочном виде. Проверь, что работает так же.
2. Создай стрелочную `square(n) => n * n` (в одну строку).
3. Создай стрелочную `greet(name)`, которая возвращает `Привет, <name>!`. Проверь в консоли.
4. **Вопрос на подумать:** что вернёт эта функция?
   ```js
   const double = n => { n * 2 };
   console.log(double(5));
   ```
   Почему так? (Подсказка: посмотри — есть ли `return` внутри `{ }`.)

## Кусочек 5. Функция вызывает функцию

**Теория.** Функции — «строительные блоки». Маленькие собираются в большие. Это главное, зачем они нужны.

```js
const square = n => n * n;
const cube   = n => n * square(n);   // использует square

console.log(cube(3));   // 27
```

Так код становится понятным: `cube` читается как «число в кубе», даже если не смотреть внутрь. Если что-то поменяется в `square` — все места, где `square` используется, получат обновление автоматически.

**Задания:**
1. Создай `square(n)` и `cube(n)`, где `cube` использует `square`. Проверь на `n = 2`, `3`, `4`.
2. Создай:
   - `isEven(n)` — возвращает `true`, если чётное;
   - `describeParity(n)` — возвращает `"чётное"` или `"нечётное"`, используя `isEven`.
3. Создай:
   - `getArea(width, height)` — площадь прямоугольника;
   - `getPerimeter(width, height)` — периметр;
   - `describeRect(w, h)` — возвращает шаблонную строку `Площадь: X, периметр: Y`, **вызывая** первые две.

## Кусочек 6. Функции + HTML = интерактивность (то, ради чего всё)

**Теория.** В реальном коде **вся логика** обычно живёт в функциях, а обработчик клика — это всего пара строк: «прочитать поле → вызвать функцию → показать результат». Так код легче читать и менять.

```html
<input id="a" type="number">
<input id="b" type="number">
<button id="calc">Сложить</button>
<p id="out"></p>

<script>
  const sum = (a, b) => a + b;

  document.getElementById("calc").onclick = () => {
    const a = Number(document.getElementById("a").value);
    const b = Number(document.getElementById("b").value);
    document.getElementById("out").textContent = `Сумма: ${sum(a, b)}`;
  };
</script>
```

Почему так лучше, чем писать всё в `onclick`:
- `sum` можно **протестировать отдельно** в консоли: `sum(2, 3)` → `5`;
- обработчик короткий и «читается» сверху вниз;
- если завтра захотим считать `a - b`, поменяем только вызов.

**Задания:**
1. Вынеси из примера на страницу: `sum`, поле `a`, поле `b`, кнопка, `<p>`. Проверь на `2 + 3` → `Сумма: 5`.
2. Сделай по той же схеме **`multiply(a, b)`** и кнопку «Умножить». Используй ту же разметку, только один `<p>` и другую кнопку.
3. **Проверка возраста.** Функция `getAge(birthYear)` возвращает `2026 - birthYear`. Поле + кнопка + `<p>`: `Тебе <age> лет.`
4. **Бонус — валидация.** В калькуляторе из №1: если одно из полей пустое — выведи в `<p>` `Введите оба числа` вместо суммы. (Подсказка: проверь `.value` до `Number`, потому что `Number("")` → `0`, а это не отличить от настоящего нуля.)

## Кусочек 7. Частые ошибки новичков (прочитай перед проверкой своих заданий)

**Теория + примеры:**

1. **Забыл вызвать функцию** — написал `sum(a, b)` без `()`, ничего не произошло.
2. **Забыл `return`** — функция вернула `undefined`, хотя внутри печатала в консоль.
   ```js
   function sum(a, b) { a + b; }   // ❌ return нет — вернёт undefined
   function sum(a, b) { return a + b; } // ✅
   ```
3. **`console.log` вместо `return`** — всё «работает», но результат **нельзя использовать** дальше.
   ```js
   function sum(a, b) { console.log(a + b); }
   const x = sum(2, 3);   // x === undefined, а 5 «увидели в консоли»
   ```
4. **Стрелочная с фигурными скобками без `return`**:
   ```js
   const double = n => { n * 2 };        // ❌ вернёт undefined
   const double = n => n * 2;             // ✅ неявный return
   const double = n => { return n * 2; }; // ✅ явный return
   ```
5. **Забыл `Number()` при чтении `.value`** — получил конкатенацию строк: `"5" + "3" = "53"`.
6. **Не то имя при вызове** — `summ(2, 3)` → `ReferenceError: summ is not defined`. Читай ошибку в консоли.
7. **Функция объявлена ниже места, где используется через `const`**:
   ```js
   console.log(square(3));          // ❌ ReferenceError
   const square = n => n * n;
   ```
   (А вот `function square(n) { return n * n; }` — «поднимается» вверх и работает. Стрелочные — нет.)

**Задания:**
1. **Найди ошибку:** почему `result === undefined`?
   ```js
   function sum(a, b) { a + b; }
   const result = sum(2, 3);
   console.log(result);
   ```
2. **Найди ошибку:**
   ```js
   const double = n => { n * 2 };
   console.log(double(5));   // undefined
   ```
3. **Найди ошибку:**
   ```js
   const multiply = (a, b) => a * b;
   const a = document.getElementById("a").value;
   const b = document.getElementById("b").value;
   console.log(multiply(a, b));   // "55" вместо 25 при a=5, b=5
   ```
4. **Найди ошибку:**
   ```js
   console.log(cube(3));                 // ReferenceError
   const cube = n => n * n * n;
   ```
