# Практическое задание: База данных «Библиотека» в SQLite

## Часть 1. Создание базы данных через DB Browser for SQLite

**Что нужно установить:** [DB Browser for SQLite](https://sqlitebrowser.org/) (бесплатный).

### Шаги:

**Шаг 1. Создание файла базы данных**
1. Открой DB Browser → нажми **«New Database»**.
2. Выбери папку и сохрани файл под именем `library.db`.

**Шаг 2. Создание таблиц через вкладку «Database Structure»**

> Вместо ручного создания через интерфейс можно (и быстрее) создать все таблицы одним SQL‑скриптом. Открой вкладку **«Execute SQL»** и выполни:

```sql
CREATE TABLE authors (
    id      INTEGER PRIMARY KEY AUTOINCREMENT,
    name    TEXT NOT NULL,
    country TEXT
);

CREATE TABLE books (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    title     TEXT NOT NULL,
    author_id INTEGER,
    year      INTEGER,
    price     REAL,
    FOREIGN KEY (author_id) REFERENCES authors(id)
);

CREATE TABLE readers (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    name  TEXT NOT NULL,
    phone TEXT,
    city  TEXT
);

CREATE TABLE loans (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    book_id       INTEGER,
    reader_id     INTEGER,
    date_taken    TEXT,
    date_returned TEXT,
    FOREIGN KEY (book_id)   REFERENCES books(id),
    FOREIGN KEY (reader_id) REFERENCES readers(id)
);
```

После нажатия **«Execute»** (▶) и **«Write Changes»** (💾) — 4 таблицы появятся в левом списке.

## Часть 3. Задания на SQL‑запросы

### Уровень 1. Простые запросы (SELECT, WHERE, ORDER BY)

1. Выведи название и год всех книг.
2. Найди все книги, изданные после 1950 года.
3. Выведи книги стоимостью больше 800, отсортировав по цене по убыванию.
4. Найди всех читателей из Москвы.
5. Выведи 3 самые дорогие книги.
6. Посчитай общее количество книг в таблице `books`.
7. Найди среднюю цену книги.

### Уровень 2. Группировка (GROUP BY)

8. Для каждого автора посчитай количество его книг в базе.
9. Найди среднюю цену книги по каждому автору.
10. Выведи города, в которых больше одного читателя.

### Уровень 3. JOIN (объединение таблиц)

11. Выведи название книги **вместе с именем её автора** (`books JOIN authors`).
12. Выведи список всех книг, изданных авторами из России.
13. Выведи имя читателя, название книги и дату выдачи для каждой выдачи (`loans JOIN readers JOIN books`).
14. Найди все книги, которые **сейчас на руках** (у которых `date_returned IS NULL`), и покажи имя читателя.
15. Посчитай, сколько книг взял каждый читатель (имя читателя + количество).
16. Выведи имя читателя и сумму стоимости всех книг, которые он когда‑либо брал.
17. Найди читателей, которые **не брали ни одной книги** (используй `LEFT JOIN`).
18. Выведи авторов, чьи книги ни разу не выдавались (используй `LEFT JOIN` + `IS NULL`).
