# Билеты для зачёта по базам данных


## Указания для студента

**Билет состоит из двух заданий:**

**Задание 1 — проектирование базы данных.**
По приведённому описанию предметной области необходимо:
1. Выделить сущности и их атрибуты.
2. Определить связи между сущностями и их типы (1:1, 1:M, M:N).
3. Построить ER-модель (в любой удобной нотации).
4. Привести схему таблиц с указанием первичных и внешних ключей.

**Задание 2 — SQL-запросы.**
Дана единая для всех билетов таблица `sales` (продажи в магазине). По приведённым бизнес-задачам необходимо написать SQL-запросы.

**Структура таблицы `sales`:**

| Поле | Тип | Описание |
|---|---|---|
| `id` | INT | идентификатор записи |
| `product` | VARCHAR | название товара |
| `category` | VARCHAR | категория товара |
| `price` | DECIMAL | цена за единицу |
| `quantity` | INT | количество проданных единиц |
| `seller` | VARCHAR | ФИО продавца |
| `sale_date` | DATE | дата продажи |

**Пример данных:**

| id | product | category | price | quantity | seller | sale_date |
|----|---------|----------|-------|----------|--------|-----------|
| 1 | Ноутбук | Электроника | 50000 | 2 | Иванов | 2024-03-01 |
| 2 | Мышь | Электроника | 1500 | 10 | Петров | 2024-03-01 |
| 3 | Стол | Мебель | 8000 | 3 | Иванов | 2024-03-02 |
| 4 | Кресло | Мебель | 12000 | 1 | Сидоров | 2024-03-03 |
| 5 | Клавиатура | Электроника | 3000 | 5 | Петров | 2024-03-04 |

## БИЛЕТ №1. Библиотека

**Задание 1.**
Библиотеке нужна информационная система. Известно, что в библиотеке много книг, и у одной книги может быть несколько авторов; один автор может написать много книг. Читатели берут книги домой, и библиотека должна знать, кто, когда взял и когда вернул книгу. Нужно уметь находить все книги конкретного автора и всю историю выдач конкретного читателя.

Спроектируйте базу данных: опишите сущности, их атрибуты и связи, постройте ER-модель и приведите схему таблиц.

**Задание 2.**
Используя таблицу `sales`:
1. Магазин хочет узнать, какие товары продаются дороже 5000 рублей, от самых дорогих к дешёвым.
2. Руководству нужно понять, сколько единиц товара продал каждый продавец, и оставить только тех, кто продал больше 5 единиц.

## БИЛЕТ №2. Интернет-магазин

**Задание 1.**

Клиенты оформляют заказы: в одном заказе может быть несколько разных товаров, для каждого указывается количество. У заказа есть дата и текущий статус (новый, оплачен, доставлен).

Спроектируйте базу данных под эти требования: сущности, атрибуты, связи, ER-модель, схема таблиц.

**Задание 2.**
Используя таблицу `sales`:
1. Нужно посмотреть все продажи категории «Электроника», отсортированные по дате.
2. Маркетологам нужно узнать среднюю цену товара по каждой категории и оставить только категории со средней ценой выше 3000 рублей.

## БИЛЕТ №4. Больница

**Задание 1.**

Один пациент может побывать у разных врачей, а один врач принимает много пациентов. Спроектируйте базу данных под эти требования: сущности, атрибуты, связи, ER-модель и схема таблиц.

**Задание 2.**
