## Теоретическая справка

### Что такое наследование?

**Наследование** — механизм ООП, позволяющий создавать новый класс на основе уже существующего. Новый класс (**производный**, или **наследник**) автоматически получает поля и методы **базового** класса и может добавлять свои.

**Зачем это нужно:**
- Повторное использование кода.
- Построение иерархий «является» (студент — это человек, круг — это фигура).
- Возможность переопределять поведение базового класса.

### Синтаксис

```cpp
class Базовый {
    // ...
};

class Производный : public Базовый {
    // ...
};
```

### Что происходит с уровнями доступа при наследовании?

| Член базового класса | `public` наследование | `protected` наследование | `private` наследование |
|----------------------|:---:|:---:|:---:|
| `public`             | `public`    | `protected` | `private` |
| `protected`          | `protected` | `protected` | `private` |
| `private`            | **недоступен** | **недоступен** | **недоступен** |

**Главное правило:** `private`-члены базового класса **никогда** не доступны из наследника. Именно для этого существует `protected` — он доступен наследникам, но скрыт от внешнего мира.

### Когда использовать `protected`?

- Когда наследнику **нужно** работать с полем или методом базового класса напрямую.
- Когда вы не хотите давать к этому доступ извне.
- **Правило хорошего тона:** используйте `protected` только когда это действительно оправдано. Слишком много `protected` — признак плохого проектирования.

### Порядок вызова конструкторов

При создании объекта производного класса:
1. Сначала вызывается **конструктор базового класса**.
2. Затем — **конструктор производного класса**.

При разрушении — наоборот.

## Задание 1. Первый наследник

Создайте базовый класс `Person` (человек) и производный класс `Student` (студент).

**Базовый класс `Person`:**
```cpp
class Person {
protected:
    std::string name;   // Имя — доступно наследникам
    int age;            // Возраст — доступно наследникам

private:
    std::string passport;  // Паспорт — скрыт от всех

public:
    Person(const std::string& n, int a, const std::string& p)
        : name(n), age(a), passport(p) {}

    void introduce() const {
        std::cout << "Меня зовут " << name
                  << ", мне " << age << " лет.\n";
    }

    std::string getPassport() const { return passport; }
};
```

**Производный класс `Student`:**
```cpp
class Student : public Person {
private:
    std::string university;
    int course;

public:
    Student(const std::string& n, int a, const std::string& p,
            const std::string& uni, int c)
        : Person(n, a, p), university(uni), course(c) {}

    void study() const {
        std::cout << name << " учится в " << university
                  << " на " << course << " курсе.\n";
    }
};
```

### Что нужно сделать

1. Скомпилируйте и запустите:
   ```cpp
   int main() {
       Student s("Иван", 19, "1234 567890", "МГУ", 2);
       s.introduce();  // метод базового класса
       s.study();      // собственный метод
       return 0;
   }
   ```

2. **Проверьте и объясните в отчёте** (раскомментируйте по очереди):

   ```cpp
   int main() {
       Student s("Иван", 19, "1234 567890", "МГУ", 2);

       // s.name;      // ??? — что скажет компилятор?
       // s.age;       // ???
       // s.passport;  // ???

       std::cout << s.getPassport() << "\n";  // ??? — работает или нет?

       return 0;
   }
   ```

**Вопросы:**
- Почему `name` и `age` доступны из `Student::study`, но не из `main`?
- Почему `passport` недоступен даже из `Student::study`?
- Зачем нужен `getPassport()`, если `passport` — `private`?

## Задание 2. Наследник собственного наследника

Создайте класс `ExcellentStudent` (отличник), наследующий от `Student`.

**Требования:**
- Поле `private double averageGrade` — средний балл.
- Конструктор, принимающий все параметры «по цепочке»: `Person` → `Student` → `ExcellentStudent`.
- Метод `printDiploma()` — использует поля `name`, `university`, `averageGrade`.

```cpp
class ExcellentStudent : public Student {
private:
    double averageGrade;

public:
    ExcellentStudent(const std::string& n, int a, const std::string& p,
                     const std::string& uni, int c, double avg)
        : Student(n, a, p, uni, c), averageGrade(avg) {}

    void printDiploma() const {
        std::cout << "Студент " << name
                  << " (" << university << ") — отличник, средний балл "
                  << averageGrade << "\n";
    }
};
```

**Проверьте:**
```cpp

    ExcellentStudent e("Анна", 20, "5678 123456", "МФТИ", 3, 4.9);
    e.introduce();      // метод Person
    e.study();          // метод Student
    e.printDiploma();   // собственный метод
    return 0;
}
```

**Вопрос:** докажите, что `protected`-члены доступны на **любой** глубине цепочки наследования. Что было бы, если бы `name` был `private`?

## Задание 3. Иерархия геометрических фигур

Спроектируйте иерархию фигур.

**Базовый класс `Shape`:**
```cpp
class Shape {
protected:
    std::string color;

public:
    Shape(const std::string& c) : color(c) {}
    virtual ~Shape() {}   // виртуальный деструктор — обсудим позже

    std::string getColor() const { return color; }
};
```

**Производный класс `Circle`:**

- Метод `double area() const` — площадь круга.

**Производный класс `Rectangle`:**
- `private double width, height;`
- Методы `area()`, `perimeter()`, `print()`.

**Производный класс `Square` (наследник `Rectangle`):**
- Один параметр `side`.
- Конструктор вызывает `Rectangle(side, side, color)`.

**Проверьте:**

## Задание 6. Сокрытие имени (name hiding) — бонус

Иногда наследник объявляет метод с тем же именем, что и в базовом классе. Это **не перегрузка**, а **сокрытие**.

```cpp
class Base {
public:
    void show() { std::cout << "Base::show\n"; }
    void show(int x) { std::cout << "Base::show(int)\n"; }
};

class Derived : public Base {
public:
    void show() { std::cout << "Derived::show\n"; }
};

int main() {
    Derived d;
    d.show();       // Derived::show — ок
    // d.show(10);  // Ошибка: Base::show(int) скрыт!

    d.Base::show();     // Явный вызов базового — работает
    d.Base::show(10);   // Тоже работает
    return 0;
}
```

**Вопрос:** почему вызов `d.show(10)` не компилируется, хотя `Base::show(int)` существует? Как это исправить через `using Base::show;`?

## Частые ошибки

| Ошибка | Причина |
|--------|---------|
| `error: 'X' is private within this context` | Пытаетесь достучаться до `private`-члена базового класса из наследника. Нужен `protected`. |
| `error: no matching function for call to 'Base::Base()'` | У базового класса нет конструктора по умолчанию, а наследник его не вызывает явно. |
| `error: 'X' is inaccessible` | Неверный тип наследования (`private`/`protected`), поле стало недоступным извне. |
| `error: no matching function` при вызове перегруженного метода | Сокрытие имени — используйте `using Base::method;`. |


## Главная мысль

> **`private`** — «это только моё».
> **`protected`** — «это моё и моих наследников».
> **`public`** — «это для всех».
>
> Наследование позволяет строить иерархии, а `protected` — делиться внутренними данными с наследниками, не открывая их всему миру.
