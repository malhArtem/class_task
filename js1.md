## Кусочек 1. Переменные

**Теория.** Переменная — «коробка» с именем, где хранится значение. Два способа объявить:
- `let` — если значение будет **меняться**;
- `const` — если значение **фиксировано** (используем по умолчанию).

```js
let age = 15;
const name = "Аня";
```

Имена: латиница, цифры, `_`, `$`; не начинать с цифры; регистр важен (`age` и `Age` — разные).

**Задания:**
1. Создай `const city` со значением `"Москва"` и `let temperature` со значением `20`. Выведи обе переменные через `console.log`.
2. Поменяй `temperature` на `25` и снова выведи.
3. Попробуй сделать `city = "Казань"`. Что произошло и почему?

## Кусочек 4. Строки и шаблонные строки

**Теория.** Строка — текст в кавычках: `"привет"`, `'JS'`. Склеивать через `+` можно, но удобнее — **шаблонные строки** в обратных кавычках `` ` `` с подстановкой `${...}`:

```js
const name = "Аня";
console.log(`Привет, ${name}!`);   // Привет, Аня!
```

Внутри `${}` можно писать выражения: `` `2 + 2 = ${2 + 2}` ``.

**Задания:**
1. Создай `const name = "Иван"` и `const city = "Казань"`. Выведи через шаблонную строку: `Иван живёт в городе Казань.`
2. Выведи то же самое через обычную строку с `+`. Сравни — какой способ читать легче?
3. Выведи: `7 + 4 = 11` — где `7`, `4` и `11` подставлены через `${}`, а не написаны руками.

## Кусочек 5. Сравнение и логика

**Теория.** Сравнение даёт `true` или `false`:

```js
5 > 3     // true
5 >= 5    // true
5 === 5   // true — строгое равенство, используем его!
5 !== 3   // true — не равно
```

Логические операторы:
```js
true && false   // false — И (оба true)
true || false   // true  — ИЛИ (хотя бы один)
!true           // false — НЕ
```

**Правило:** для сравнения всегда `===` и `!==`, не `==` и `!=`.

**Задания:**
1. Выведи результаты: `10 > 5`, `10 === 10`, `10 === "10"`, `10 !== 5`.
2. Создай `const age = 16`. Выведи `true` или `false` для проверки `age >= 18`.
3. Выведи: «возраст от 14 до 18» — через `age >= 14 && age <= 18`.

## Кусочек 6. Ветвление `if / else`

**Теория.** Условие в `if` — это выражение, дающее `true`/`false`. Если `true` — блок выполняется, иначе — пропускается. Если нужно два исхода — добавляем `else`.

```js
if (age >= 18) {
  console.log("Взрослый");
} else {
  console.log("Ребёнок");
}
```

Если путей больше двух — `else if` (проверки идут **сверху вниз**, срабатывает **первая подходящая**):

```js
if (score >= 90)      console.log("A");
else if (score >= 70) console.log("B");
else                  console.log("C");
```

**Задания:**
1. Создай `const age = 15`. Через `if/else` выведи `Доступ разрешён`, если `>= 18`, иначе — `Доступ запрещён`.
2. Создай `const score = 75`. Через `if / else if / else` выведи:
   - `>= 90` → «Отлично»
   - `>= 70` → «Хорошо»
   - `>= 50` → «Удовлетворительно»
   - иначе → «Не сдал»
3. **Найди проблему:** почему для `score = 95` код ниже печатает «C»?
   ```js
   if (score >= 50)      console.log("C");
   else if (score >= 90) console.log("A");
   ```
   Исправь порядок.

## Кусочек 7. Тернарный оператор (короткий `if/else`)

**Теория.** Когда исходов всего два и присваиваем значение — удобно:

```js
условие ? значениеЕслиTrue : значениеЕслиFalse
```

```js
const status = age >= 18 ? "взрослый" : "ребёнок";
```

Хорошо работает внутри шаблонной строки:
```js
console.log(`Ты ${age >= 18 ? "можешь" : "не можешь"} голосовать`);
```

Не вкладывай тернарники друг в друга — читаемость падает.

**Задания:**
1. Создай `const n = 7`. Через тернарник выведи `чётное` или `нечётное` (подсказка: `n % 2 === 0`).
2. Создай `const isLoggedIn = false`. Выведи через тернарник: `Добро пожаловать` или `Войдите в систему`.
3. Перепиши это решение через `if/else` — сравни, что читается лучше.

## Кусочек 8. Truthy / falsy

**Теория.** В `if` можно передать не только `true/false` — JS сам приведёт значение к boolean.

**Falsy (считаются ложью), их всего 6:**
```js
false, 0, "", null, undefined, NaN
```

**Всё остальное — truthy**, включая `"0"`, `" "`, `[]`, `{}`, `-1`.

```js
const name = "";
if (name) console.log("Привет");
else      console.log("Имя не введено");   // сработает это
```

⚠️ `[]` и `{}` — truthy, хотя «пустые».

**Задания:**
1. Что выведет? Проверь в консоли и объясни:
   ```js
   if ([])      console.log("A");
   if ("")      console.log("B");
   if ("0")     console.log("C");
   if (0)       console.log("D");
   ```
2. Спроси имя через `prompt`. Если пустая строка — выведи `Аноним`, иначе — введённое имя. Используй простую проверку `if (name)`.
3. Объясни: почему `Boolean("false")` → `true`? (Подсказка: JS смотрит на длину строки, а не на её содержимое.)

## Кусочек 9. Мини-программа (собираем всё вместе)

**Теория.** Сейчас у тебя уже есть всё для маленькой программы: `prompt` → ввод, `Number(...)` → приведение к числу, шаблонные строки → вывод, `if/else` → логика.

```js
const year = Number(prompt("Год рождения?"));
const age = 2026 - year;
alert(`Тебе ${age} лет.`);
```

3. **Чётное/нечётное.** Спроси число. Через тернарник выведи `чётное` или `нечётное`.
4. **Калькулятор.** Спроси два числа. Выведи сумму, разность, произведение и частное. Не забудь `Number(...)`.
