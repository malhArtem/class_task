# ЧАСТЬ 1. ТЕОРИЯ

## 1. Что такое CSS

**CSS (Cascading Style Sheets)** — язык описания внешнего вида HTML-документа. HTML создаёт структуру (что это: заголовок, абзац, ссылка), а CSS говорит, **как это выглядит**: цвет, размер, шрифт, отступы, выравнивание.

Слово «каскадные» означает, что стили применяются по правилам приоритета: если на элемент влияет несколько правил — побеждает более «весомое».

---

## 2. Способы подключения CSS

**1. Внешний файл** — самый удобный и правильный способ:
```html
<link rel="stylesheet" href="style.css">
```
Стили лежат в отдельном файле `style.css`, который подключается в `<head>`.

**2. Внутренний** — прямо в HTML, в теге `<style>`:
```html
<style>
  /* стили */
</style>
```

**3. Инлайновый** — прямо в теге через атрибут `style`:
```html
<p style="color: red;">текст</p>
```

**Приоритет:** инлайновый > внутренний > внешний (при равной специфичности селекторов).

---

## 3. Синтаксис правила CSS

Правило состоит из **селектора** и **блока объявлений**:

```
селектор {
  свойство: значение;
  свойство: значение;
}
```

Пример:
```css
h1 {
  color: navy;
  font-size: 32px;
}
```

**Правила оформления:**
- после `свойства` — двоеточие `:`
- после `значения` — точка с запятой `;`
- весь блок — в фигурных скобках `{ }`
- комментарии: `/* текст */`

---

## 4. Селекторы (базовые)

**По тегу** — выбирает все элементы данного типа:
```
p { ... }      /* все абзацы */
h1 { ... }     /* все заголовки h1 */
a  { ... }     /* все ссылки */
```

**Универсальный `*`** — выбирает вообще все элементы. Часто применяют для сброса отступов:
```
* { margin: 0; padding: 0; }
```

**Групповой** — применить стили сразу к нескольким селекторам:
```
h1, h2, h3 { color: navy; }
```

**Псевдокласс `:hover`** — состояние при наведении курсора:
```
a:hover { ... }
```

**По классу `.имя` и по id `#имя`** — существуют, но мы их пока не используем.

---

## 5. Основные свойства

### Текст и шрифт
| Свойство | Что делает | Примеры значений |
|----------|-----------|------------------|
| `color` | цвет текста | `red`, `#333`, `rgb(0,0,0)` |
| `font-size` | размер шрифта | `16px`, `120%` |
| `font-family` | шрифт | `Arial, sans-serif` |
| `font-weight` | жирность | `normal`, `bold` |
| `font-style` | наклон | `normal`, `italic` |
| `text-align` | выравнивание | `left`, `center`, `right` |
| `text-decoration` | подчёркивание | `none`, `underline` |
| `line-height` | межстрочный интервал | `1.5`, `20px` |

### Блоки и оформление
| Свойство | Что делает |
|----------|-----------|
| `background-color` | цвет фона |
| `width` / `height` | ширина / высота |
| `padding` | внутренний отступ (между содержимым и краем) |
| `margin` | внешний отступ (расстояние до соседних элементов) |
| `border` | рамка: `1px solid black` |
| `border-radius` | скругление углов |
| `box-shadow` | тень |
| `cursor` | вид курсора (`pointer` — «рука») |

## 6. Про `margin`

**`margin`** — это **внешний отступ**. Он добавляет пустое пространство **вокруг** элемента — между ним и соседними элементами или краем родителя. Сам `margin` прозрачный: фона у него нет.

### Зачем нужен `margin`

- оттолкнуть один элемент от другого по вертикали или горизонтали
- отодвинуть элемент от края страницы
- **центрировать блок** по горизонтали (см. ниже)
- убрать «прилипание» заголовка к тексту над ним

### Сокращённая запись

`margin` можно задавать одной строкой — значения идут **по часовой стрелке, начиная сверху**:

```
margin: 10px;                  /* все четыре стороны */
margin: 10px 20px;             /* верх/низ = 10, лево/право = 20 */
margin: 10px 20px 30px;        /* верх=10, лево/право=20, низ=30 */
margin: 10px 20px 30px 40px;   /* верх=10, право=20, низ=30, лево=40 */
```

### Отдельные стороны

Можно задавать стороны явно:
```
margin-top: 20px;
margin-right: 10px;
margin-bottom: 20px;
margin-left: 10px;
```

### Важная деталь: вертикальные margin схлопываются

Если у одного элемента `margin-bottom: 30px`, а у следующего `margin-top: 20px`, то расстояние между ними будет **не 50px**, а **30px** — берётся **больший** из двух. Это называется «схлопывание margin» (margin collapse). Это работает только для вертикальных отступов (top/bottom), горизонтальные просто суммируются.

Запомнить: **соседние вертикальные margin не складываются, а «поглощают» друг друга**.

### Центрирование по горизонтали

Если у элемента задана `width`, то `margin: 0 auto;` **центрирует его** по горизонтали. Значение `auto` говорит браузеру: «посчитай отступы слева и справа так, чтобы элемент оказался посередине».

Пример:
```css
img {
  width: 200px;
  margin: 0 auto;
}
```
Картинка встанет по центру горизонтали.

### Как не путать `margin` и `padding`

- **`margin`** — расстояние **до других элементов** (снаружи)
- **`padding`** — расстояние **от содержимого до края** самого элемента (внутри)

Простой ориентир: если нужно, чтобы текст внутри кнопки «дышал» — это `padding`. Если нужно, чтобы кнопка не липла к соседней кнопке — это `margin`.

---

## 7. Единицы измерения

| Единица | Что это | Пример |
|---------|---------|--------|
| `px` | пиксели, фиксированно | `16px` |
| `%` | процент от родителя | `50%` |
| `em` | относительно размера шрифта родителя | `1.5em` |
| `rem` | относительно размера шрифта `<html>` | `1.5rem` |
| `vh` / `vw` | % от высоты / ширины окна | `100vh` |

Для старта достаточно `px` и `%`.

---

## 8. Цвета

Три способа:
- **Именованные:** `red`, `blue`, `darkgreen`, `navy`
- **HEX:** `#333`, `#1a3d7c`, `#ffffff`
- **RGB:** `rgb(255, 0, 0)`, `rgba(255, 0, 0, 0.5)` (последнее число — прозрачность)

---

## 9. Каскад и приоритет

Если несколько правил нацелены на один элемент:
1. Побеждает более **специфичное** правило (id > класс > тег)
2. При равной специфичности — то, что написано **ниже** в файле

Поэтому порядок правил в CSS важен.

# ЧАСТЬ 2. ЗАДАНИЕ

## Задание: «Личная страница»

### HTML (можно копировать, содержимое — своё):

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Моя страница</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>

  <h1>Привет, я [Ваше имя]</h1>

  <h2>Обо мне</h2>
  <p>Пара предложений о себе.</p>

  <h2>Мои увлечения</h2>
  <p>Что вы любите делать в свободное время.</p>

  <h2>Полезные ссылки</h2>
  <a href="https://google.com">Google</a>
  <a href="https://youtube.com">YouTube</a>
  <a href="https://github.com">GitHub</a>

  <hr>

  <p>Сделано в 2026 году</p>

</body>
</html>
```

### Что нужно сделать в `style.css`

Используйте только селекторы: `body`, `h1`, `h2`, `p`, `a`, `a:hover`, `hr`.

**1. `body`**
- задайте светлый фон (`background-color`)
- задайте шрифт `Arial, sans-serif`
- задайте внутренние отступы со всех сторон (`padding`)
- задайте цвет текста, отличный от чёрного (например, тёмно-серый)

**2. `h1`**
- задайте свой цвет (например, тёмно-синий)
- задайте размер шрифта
- выровняйте по центру
- добавьте нижнюю границу (`border-bottom`)
- добавьте внутренний отступ снизу, чтобы текст не прилипал к линии

**3. `h2`**
- задайте цвет, отличный от `h1`
- задайте размер шрифта
- добавьте **внешний** отступ сверху (`margin-top`), чтобы заголовок не прилипал к предыдущему тексту

**4. `p`**
- задайте размер шрифта
- задайте межстрочный интервал (`line-height`)

**5. `a`**
- задайте цвет текста (например, белый)
- уберите подчёркивание
- сделайте из ссылки «кнопку»: добавьте внутренние отступы (`padding`), цвет фона, скругление углов
- добавьте **внешний** отступ справа (`margin-right`), чтобы кнопки не слипались
- добавьте свойство, чтобы курсор становился «рукой» (`cursor`)

**6. `hr`**
- уберите стандартную рамку (`border: none`)
- задайте тонкую верхнюю линию (`border-top`)
- добавьте внешние отступы сверху и снизу (`margin`)

## Критерии готовности

1. Страница открывается и стили применяются
2. `h1` отличается от `h2` цветом и размером
3. Ссылки выглядят как кнопки и меняют цвет при наведении
4. `hr` — тонкая линия, а не стандартная «вдавленная»
5. Нет синтаксических ошибок (пропущенных `;`, `{`, `}`)
