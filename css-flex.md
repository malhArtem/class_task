## Уровень 1. Базовые раскладки

**1. Ряд из трёх блоков**  
Даны три `div`. Сделайте flex-ряд.  
Требования:
- выравнивание по центру контейнера;
- отступ между блоками 20px;
- попробуйте по очереди `justify-content: flex-start`, `center`, `space-between`, `space-around`;
- покажите разницу в DevTools.

**2. Навигация**  
Сделайте шапку: слева логотип (текст), справа 4 ссылки.  
Требования:
- логотип прижат влево, ссылки — вправо;
- всё выровнено по вертикали по центру;
- используйте `justify-content: space-between`.

**3. Центрирование карточки**  
Сделайте карточку 300×200 px.  
Требования:
- карточка строго по центру экрана по горизонтали и вертикали;
- высота контейнера — `100vh`;
- только Flexbox: `justify-content: center` и `align-items: center`.

**4. Вертикальный список**  
Сделайте список из 5 пунктов.  
Требования:
- пункты идут в столбик;
- растягиваются по ширине контейнера;
- последний пункт прижат к низу (`margin-top: auto`).

## Уровень 2. Компоненты

**5. Карточки товаров**  
Контейнер с 6 карточками.  
Требования:
- `flex-wrap: wrap`, `gap: 20px`;
- каждая карточка: `flex: 1 1 250px`;
- внутри карточки: заглушка вместо фото, заголовок, цена, кнопка;
- кнопка прижата к низу карточки (карточка — flex-колонка, кнопка — `margin-top: auto`).

**6. Медиа-объект**  
Аватар 64×64 px, справа текст.  
Требования:
- аватар не сжимается (`flex-shrink: 0`);
- текст занимает всё оставшееся место (`flex: 1`);
- длинный текст переносится, ничего не вылезает.

**7. Боковая панель**  
Двухколоночный макет.  
Требования:
- sidebar — 250px;
- content — всё остальное (`flex: 1`);
- обе колонки одной высоты.

**8. Панель инструментов**  
Слева группа из 3 кнопок, справа — 2 кнопки.  
Требования:
- между группами свободное пространство (`space-between`);
- внутри групп — небольшие отступы;
- используйте вложенные flex-контейнеры.

**9. Хлебные крошки**  
Цепочка: Главная / Каталог / Товар.  
Требования:
- элементы в ряд;
- разделители между ними;
- выравнивание по центру по вертикали;
- не используются списки с `float`.

## Уровень 3. Комплексные макеты

**10. Шапка сайта**  
Лого, меню, кнопка «Войти».  
Требования:
- лого слева, меню по центру, кнопка справа;
- всё в одну строку;
- без media-запросов и адаптива.

**11. «Святой Грааль» на Flexbox**  
Header, footer, main.  
Требования:
- внутри main: article (`flex: 1`) и aside (200px);
- footer прижат к низу, если контента мало (`body` — flex-колонка, `main` — `flex: 1`);
- только Flexbox.

**12. Галерея**  
8 блоков разной высоты.  
Требования:
- `flex-wrap: wrap`;
- блоки тянутся (`flex-grow: 1`);
- между блоками `gap: 15px`;
- последняя строка не растягивается на всю ширину (добавьте пустой flex-элемент или используйте `flex-grow: 0` для последнего).

**13. Перестановка через `order`**  
Даны 3 блока в HTML: A, B, C.  
Требования:
- визуальный порядок: C, A, B;
- HTML не менять;
- используйте только `order`.

**14. Sticky footer**  
Страница с коротким контентом.  
Требования:
- footer всегда внизу окна;
- не перекрывает контент;
- `min-height: 100vh`, `flex-direction: column`, `main { flex: 1 }`.

**15. Ценовые карточки**  
3 тарифа. Средний выделен.  
Требования:
- средний больше (`flex: 1.2`), тень, другой фон;
- выравнивание по центру;
- все три в одну строку.

**16. Чат**  
Сообщения: аватар, имя, текст.  
Требования:
- свои сообщения справа, чужие слева;
- используйте `flex-direction: row-reverse` и `align-self`;
- текст не выходит за границы.

**17. Дашборд**  
Sidebar, header, 4 виджета.  
Требования:
- два виджета по 50%, два по 25%;
- `flex-wrap` и `flex-basis`;
- всё в одной фиксированной раскладке.

## Бонус (со звёздочкой)

**18. Горизонтальный таймлайн**  
5 точек и линии между ними.  
Требования:
- линия тянется (`flex: 1`);
- точки фиксированного размера;
- всё выровнено по центру.

**19. Панель уведомлений**  
Иконка, текст, кнопка закрытия.  
Требования:
- иконка и кнопка не сжимаются;
- текст занимает всё место;
- кнопка прижата вправо.

**20. Макет статьи**  
Заголовок, мета-информация, текст, блок тегов.  
Требования:
- мета-информация в ряд с отступами;
- теги переносятся (`flex-wrap`);
- основной текст занимает всю ширину.

## Критерии оценки

- **5** — все задания выполнены, семантичный HTML, чистый CSS, нет лишних обёрток, Flexbox использован осознанно.
- **4** — основные задания сделаны, мелкие недочёты по выравниванию или переносу.
- **3** — сделаны только базовые задания, есть проблемы с осями и `flex-wrap`.
- **2** — Flexbox не используется или есть грубые ошибки.

## Что проверять в DevTools

- Включён ли `display: flex`.
- Как работают `justify-content` и `align-items`.
- Не забыт ли `flex-wrap`.
- Нет ли горизонтального скролла.
- Для текста внутри flex-элемента: `min-width: 0`, если он не сжимается.
