# Практикум по CSS Grid
## Уровень 1. Разминка

### Задание 1. «Оживи сетку»

**Теория.**
`grid-template-columns` задаёт **столбцы** (треки по горизонтали). Единица `fr` — доля свободного места: `1fr 1fr 1fr` делит ширину на три равные части. `gap` — отступ **между** треками (не по краям). Пока ни одного трека не задано, сетка существует, но состоит из одной колонки.

**Стартовый код:**

```html
<div class="grid">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div><div>6</div>
</div>
```

```css
.grid { display: grid; gap: 8px; background: #eee; padding: 8px; }
.grid > div { background: #4a90e2; color: #fff; padding: 20px; text-align: center; }
```

**Действия:**
1. Добавь `grid-template-columns: 1fr 1fr 1fr`. Посмотри, как элементы разложились по строкам.
2. Замени на `repeat(4, 1fr)`. Отметь, что изменилось.
3. Замени на `2fr 1fr`. Замерь ширину блоков в DevTools.
4. Сделай скриншот «до/после» и подпиши в комментарии к CSS, что именно изменилось.

### Задание 2. «Доли свободного места»

**Теория.**
`fr` — это **доля свободного места после вычета фиксированных треков и `gap`**. Если трек задан в `px`, он забирает свою ширину первым, а `fr` делят остаток. `minmax(min, max)` задаёт нижнюю и верхнюю границу трека. `minmax(0, 1fr)` — страховка от «распирания» трека длинным словом: `1fr` по умолчанию имеет неявный минимум `auto` (по содержимому), а `minmax(0, 1fr)` разрешает сжаться до нуля.

**Стартовый код:**

```css
.grid { display: grid; grid-template-columns: 100px 1fr 2fr; gap: 10px; }
```

**Действия:**
1. Открой DevTools и замерь ширину всех трёх колонок.
2. Напиши в комментарии к CSS, во сколько раз средний блок уже правого и почему.
3. Замени `100px` на `200px`. Перезамерь. Убедись, что доли `1fr`/`2fr` пересчитались.
4. Добавь в один блок очень длинное слово без пробелов. Наблюдай, что произойдёт с сеткой.
5. Замени `1fr` на `minmax(0, 1fr)`. Сравни результат.

### Задание 3. «Линии и span»

**Теория.**
**Линии** — границы между треками. Нумеруются с `1`; с конца — `-1`. Запись `grid-column: 1 / 3` значит «от линии 1 до линии 3», то есть **2 колонки**. `span N` значит «занять N треков от места автоплейсмента». `-2 / -1` — «от предпоследней линии до последней», то есть прижать к правому краю. `grid-auto-rows` задаёт высоту **неявных** (автоматически созданных) строк.

**Стартовый код:**

```css
.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 80px;
  gap: 8px;
}
```

**Действия (по шагам, каждое — отдельный коммит):**
1. Сделай так, чтобы `.item-a` занимал **всю первую строку** — используй `grid-column: 1 / -1`.
2. Сделай `.item-b` на две колонки во второй строке — `grid-column: span 2`.
3. Сделай `.item-c` размером 2×2 — колонки и строки через `span`.
4. Прижми `.item-d` к самому правому столбцу — `grid-column: -2 / -1`.
5. Открой overlay сетки в DevTools и проговори про себя для каждого блока: «от линии X до линии Y = N клеток».
6. Перепиши `.item-c` с `span` на явные линии (`2 / 4`). Сравни читаемость.

### Задание 4. «ASCII-макет»

**Теория.**
`grid-template-areas` — способ рисовать макет **словами**. Каждая строка — строка сетки, каждое слово — имя области. Имя должно повторяться так, чтобы область образовывала **прямоугольник**. Элемент привязывается к области через `grid-area: имя`. Размеры треков задаются отдельно: `grid-template-columns` и `grid-template-rows`.

**Стартовый код:**

```html
<div class="page">
  <header>Header</header>
  <nav>Nav</nav>
  <main>Main</main>
  <footer>Footer</footer>
</div>
```

**Действия:**
1. Сверстай макет через `grid-template-areas`:
   ```
   header header
   nav    main
   footer footer
   ```
2. Размеры: `header` 60px, `footer` 60px, `nav` 200px, `main` — всё остальное (`1fr`).
3. Привяжи каждый элемент к своей области через `grid-area`.
4. Сделай `min-height: 100vh` у контейнера и убедись, что `main` растянулся на всё оставшееся место.
5. Замени `grid-template-areas` на эквивалент через `grid-column` / `grid-row` у каждого элемента. Сравни два варианта: какой читается быстрее при изменении макета.

### Задание 5. «Дырка в сетке»

**Теория.**
Точка `.` в `grid-template-areas` — **пустая клетка**. Это не элемент, туда ничего не кладётся, виден фон контейнера. Точек может быть несколько подряд (`. .`), каждая — отдельная пустая клетка. Если потом дать этой клетке имя области, туда можно посадить элемент.

**Действия:**

   ```
   "a a . b"
   "c c c b"
   ```

2. Привяжи четыре элемента к областям `a`, `b`, `c` и добавь пятый элемент, который **ни к чему не привязан**.
3. Сделай так, чтобы клетка `(1,3)` осталась пустой — там ничего не должно стоять.
4. Убедись в DevTools, что в этой клетке виден фон контейнера.
5. Замени `.` на имя области `d` и привяжи к ней пятый элемент. Сравни с предыдущим вариантом.

### Задание 6. «Выравнивание: 4 свойства — 4 эффекта»

**Теория.**
Есть четыре свойства, и их легко перепутать:

| Свойство | Кого выравнивает |
|---|---|
| `justify-items` / `align-items` | элементы **внутри своих клеток** |
| `justify-content` / `align-content` | **всю сетку треков** в контейнере |
| `place-items` | сокращение для `align-items` + `justify-items` |
| `justify-self` / `align-self` | то же, но для одного элемента |

`justify-*` — горизонталь, `align-*` — вертикаль. `content` работает только если у треков есть свободное место (например, при фиксированных `100px`); при `1fr` треки уже заняли всё — выравнивать нечего.

**Стартовый код:**

```css
.grid {
  display: grid;
  width: 600px;
  height: 400px;
  grid-template-columns: repeat(3, 100px);
  grid-template-rows: repeat(2, 100px);
  gap: 8px;
  background: #eee;
}
.grid > div { background: #4a90e2; color: #fff; width: 40px; height: 40px; }
```

**Действия (по одному свойству за раз, каждое — отдельный скриншот):**
1. Поставь `justify-content: center` — сетка уехала в центр по горизонтали.
2. Замени на `align-content: center` — то же по вертикали.
3. Сбрось оба, поставь `place-items: center` — блоки отцентрированы **внутри клеток**, сетка стоит слева-сверху.
4. Замени на `justify-items: end` — содержимое клеток прижалось к правому краю клеток.
5. Вернись к `justify-content: center`, но поменяй треки на `1fr 1fr 1fr`. Посмотри, что выравнивание перестало работать.
6. В комментарии к CSS напиши, почему в шаге 5 `justify-content` не даёт эффекта.

### Задание 7. «Адаптивные карточки без media query»

**Теория.**
Главный паттерн Grid: `repeat(auto-fit, minmax(220px, 1fr))`. Он читается так: «создай столько колонок, сколько влезет, каждая — не уже 220px и не шире доли свободного места». Браузер сам перестраивает сетку при изменении ширины контейнера — `@media` не нужен. Разница `auto-fit` и `auto-fill`: `auto-fit` **схлопывает** пустые треки, и элементы растягиваются на всю ширину; `auto-fill` оставляет пустые треки, и элементы не растягиваются. `grid-column: 1 / -1` растягивает элемент на всю ширину сетки.

**Стартовый код:**

```html
<div class="cards">
  <article>Card 1</article>
  <article>Card 2</article>
  <article>Card 3</article>
  <article>Card 4</article>
  <article>Card 5</article>
  <article>Card 6</article>
  <article>Card 7</article>
</div>
```

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
```

**Действия:**
1. Открой страницу и потаскай край окна. Зафиксируй, в какой момент карточки перестраиваются.
2. Оставь в HTML **три** карточки. Замени `auto-fit` на `auto-fill` и растяни окно на весь экран. Замерь ширину карточек.
3. Верни `auto-fit`. Замерь снова. Сделай скриншот обоих вариантов.
4. Добавь одну «геройскую» карточку на всю ширину — `grid-column: 1 / -1`.
5. Поменяй `minmax(220px, 1fr)` на `minmax(220px, 400px)`. Потяни окно. Отметь, как «ужимается» сетка.
6. В комментарии к CSS опиши разницу `auto-fit` / `auto-fill` одной строкой.

## Уровень 2. Комбинируем концепции

### Задание 8. «Дашборд»

**Теория.**
`areas` + `span` + `gap` собираются в один макет. `grid-template-columns` задаёт ширины столбцов, `grid-template-rows` — высоты строк. `minmax(180px, 240px)` в колонке значит «сжимайся до 180px, но не уже; не растягивайся шире 240px» — это «резиновый» трек без `@media`. `min-height: 100vh` заставляет контейнер занять весь экран по высоте, и `1fr`-строки делят остаток.

**Макет:**

```
[ header  header  header ]
[ aside   main    main   ]
[ aside   chart   chart  ]
[ footer  footer  footer ]
```

**Действия:**
1. Собери этот макет через `grid-template-areas`.
2. `aside` — фиксированная ширина 240px; `header` и `footer` — фиксированная высота.
3. `main` и `chart` — доли `1fr` по высоте.
4. Задай контейнеру `min-height: 100vh`.
5. Добавь `gap: 12px`.
6. Вставь в `main` длинный текст с `overflow: auto`. Проскролль — сетка не должна разъезжаться.
7. Сделай `aside` «резиновым»: `grid-template-columns: minmax(180px, 240px) 1fr 1fr`. Потяни окно и замерь, как `aside` сжимается до 180px и не уже.

### Задание 9. «Masonry-lite»

**Теория.**
Элементы без явных координат заполняют свободные ячейки автоматически — это **автоплейсмент**. `grid-auto-flow: row` — заполнять по строкам (по умолчанию). `grid-auto-rows` задаёт высоту **неявных** строк. `dense` — «плотный» режим: браузер возвращается назад и «затыкает» дырки элементами меньшего размера. Побочный эффект: визуальный порядок может разойтись с порядком в DOM, и тогда порядок табуляции перестаёт совпадать с тем, что видно на экране.

**Стартовый код:** 10 карточек, часть — с классом `.tall`.

**Действия:**
1. Разложи карточки сеткой `repeat(auto-fill, minmax(180px, 1fr))`.
2. Сделай `.tall` высотой в две строки — `grid-row: span 2`.
3. Сначала посмотри без `dense`. Сделай скриншот: видны дырки в раскладке.
4. Добавь `grid-auto-flow: row dense`. Сделай скриншот: дырки затянулись.
5. Походи по странице клавишей `Tab`. Зафиксируй, что порядок фокуса не совпадает с визуальным порядком.
6. В комментарии к CSS запиши, в каких случаях `dense` допустим, а в каких — нет.

## Уровень 3. Grid + Flexbox: когда что

**Теория секции.**
**Grid** — двумерный: раскладывает по странице. **Flex** — одномерный: выравнивает элементы внутри компонента по одной оси. Идиома: Grid-контейнер задаёт макет страницы, Flex — выравнивает содержимое внутри компонента. Вкладывать одно в другое — норма.

---

### Задание 10. «Карточка товара»

**Теория.**
`display: flex; flex-direction: column` — вертикальная Flex-колонка. `margin-top: auto` у последнего элемента «выталкивает» его вниз: он получает весь свободный вертикальный запас. Grid снаружи задаёт одинаковую высоту карточек (все растягиваются до высоты самой высокой строки), а Flex внутри распределяет содержимое по этой высоте.

**Структура карточки:**

```
[ картинка ]
[ название — может быть в 1–3 строки ]
[ цена ]                 [ кнопка "Купить" ]
```

**Действия:**
1. Сверстай сетку из 6 карточек: `grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`.
2. Внутри карточки сделай Flex-колонку: `display: flex; flex-direction: column`.
3. Прижми строку «цена + кнопка» к низу карточки через `margin-top: auto`.
4. Поставь в одну карточку очень длинное название (в 3 строки). Убедись, что все карточки остались одной высоты.
5. В комментарии к CSS опиши, зачем здесь Grid снаружи и Flex внутри.

### Задание 11. «Тулбар с иконкой и текстом»

**Теория.**
Flex-строка — это `display: flex` с горизонтальной осью. `align-items: center` выравнивает по вертикали, `gap` — отступы между элементами. `margin-left: auto` у правого элемента съедает весь свободный запас и прижимает его вправо. Тот же тулбар можно собрать и на Grid: `grid-template-columns: auto 1fr auto` — три колонки, средняя забирает остаток. Сравнение покажет, какой инструмент для этой задачи короче.

**Структура строки:**

```
[иконка] [текст] ........ [кнопка]
```

**Действия:**
1. Сделай контейнер Flex-строкой: `display: flex; align-items: center; gap: 8px`.
2. Отодвинь кнопку вправо через `margin-left: auto`.
3. Перепиши тот же тулбар **только на Grid** — `grid-template-columns: auto 1fr auto`.
4. Сделай скриншоты обоих вариантов и замерь количество строк CSS.
5. В комментарии к CSS напиши, какой вариант читается проще и почему.

### Задание 12. «Страница статьи»

**Теория.**
Итоговое задание собирает всё: Grid-макет страницы через `grid-template-areas`, «резиновые» колонки через `minmax`, Flex-компоненты внутри. `minmax(0, 1fr)` у `main` не даёт длинному тексту «распереть» колонку. `justify-content: space-between` на Flex разводит элементы по краям. Часть контейнеров **не нуждается** ни в Grid, ни в Flex — обычный поток тоже валидный выбор, и это тоже надо осознанно назвать в комментарии.

**Макет:**

```
header (Flex: логотип слева, навигация справа)
[ main-статья  | aside ]
footer (Flex: копирайт и соц-иконки по краям)
```

**Действия:**
1. Сверстай страницу через `grid-template-areas`.
2. Колонки задай так: `grid-template-columns: minmax(0, 1fr) minmax(220px, 320px)`. Потяни окно — `aside` ужмётся до 220px, но не уже.
3. `header` и `footer` сделай на Flex — `justify-content: space-between` для разведения краёв.
4. Внутри `aside` сделай Flex-колонку для списка ссылок.
5. `main` оставь обычным потоком — без `display: grid` и `display: flex`.
6. Напротив каждого контейнера в CSS напиши комментарий-обоснование: «тут Grid, потому что…» / «тут Flex, потому что…» / «тут без layout-свойств, потому что…».

**Критерий приёмки:** в CSS есть комментарий-обоснование на каждый контейнер, а при сужении окна макет остаётся читаемым **без единого `@media`**.

## Бонусные задания

### Бонус A. «Subgrid»

**Теория.**
`grid-template-rows: subgrid` заставляет дочернюю сетку **наследовать треки родителя**. Это решает старую проблему «карточки с одинаковой высотой заголовков» без хаков и без фиксированных высот.

**Действия:**
1. Сделай карточки с одинаковой высотой строк заголовков через `grid-template-rows: subgrid`.
2. Проверь поддержку в целевом браузере.
3. Добавь fallback для браузеров без `subgrid`.

### Бонус B. «Сетка 12 колонок»

**Теория.**
Утилитарный класс — один класс = одно свойство. `.col-4 { grid-column: span 4; }` значит «занять 4 колонки из 12». Такой набор позволяет собирать страницы в HTML, не трогая CSS.

**Действия:**
1. Сделай утилитарные классы `.col-1 … .col-12` через `grid-column: span N`.
2. Собери с их помощью простую страницу: шапка на всю ширину, две колонки по 6, три по 4.
3. Проверь, что сумма `span` в строке не превышает 12.

---

### Бонус C. «Одна и та же страница тремя способами»

**Теория.**
Одна и та же раскладка обычно решается несколькими способами. Ценность задания — не «правильный ответ», а **осознанный выбор инструмента** и умение объяснить его словами.

**Действия:**

2. Сверстай тот же макет только на Grid.
3. Сверстай тот же макет смешанно.
