### Задание 1. «Секретное имя»

Напиши функцию `hide_name(name)`, которая принимает имя и возвращает его в зашифрованном виде: первая и последняя буквы остаются, а все буквы между ними заменяются на `*`.

```python
print(hide_name("Шарик"))      # Ш***к
print(hide_name("Александра")) # А********а
print(hide_name("Ян"))         # Ян
print(hide_name(""))           # 
```

### Задание 2. «Скидка в магазине»

Напиши функцию `final_price(price, discount)`, которая считает итоговую цену товара после скидки.

`discount` — скидка в процентах. Если скидка больше 50, считать её равной 50.

**Пример работы:**
```python
print(final_price(1000, 20))   # 800.0
print(final_price(500, 10))    # 450.0
print(final_price(200, 70))    # 100.0
print(final_price(100, 0))     # 100.0
```

### Задание 3. «Приветствие»

Напиши функцию `greet(name, greeting="Привет")`, которая возвращает строку приветствия.

**Правила:**
- Если `name` — пустая строка `""`, вернуть `"Привет, незнакомец!"` (независимо от `greeting`).
- Иначе вернуть строку: `"{greeting}, {name}!"`.

**Пример работы:**
```python
print(greet("Маша"))               # Привет, Маша!
print(greet("Петя", "Здравствуй")) # Здравствуй, Петя!
print(greet(""))                   # Привет, незнакомец!
print(greet("", "Салют"))          # Привет, незнакомец!
```

Это задание проверяет:
- умение задавать параметр по умолчанию (`greeting="Привет"`);
- умение использовать условие внутри функции;
- понимание, что функция **возвращает** строку, а не печатает её.

### Задание 5. «Транспорт»

**Шаг 1.** Создай класс `Transport`:
- `__init__` принимает `name` (название), `speed` (скорость) и `wheels` (количество колёс);
- метод `go()` выводит на экран строку:  
  `"{name} едет со скоростью {speed} км/ч"`;
- метод `stop()` выводит на экран строку:  
  `"{name} остановился"`;
- метод `info()` возвращает (не выводит!) строку с названием и количеством колёс:  
  `"{name}: {wheels} колёс"`.

**Шаг 2.** Создай класс `Car(Transport)`:
- `__init__` принимает **только** `name`, а `speed` всегда `120`, `wheels` всегда `4`;
- переопределяет `go()` так, чтобы выводилось:  
  `"Машина {name} мчится со скоростью 120 км/ч"`.

**Шаг 3.** Создай класс `Bike(Transport)`:
- `__init__` принимает **только** `name`, `speed` всегда `20`, `wheels` всегда `2`;
- переопределяет `go()`:  
  `"Велосипед {name} крутит педали со скоростью 20 км/ч"`.

**Шаг 4.** Создай класс `Truck(Transport)`:
- `__init__` принимает `name` и `speed`, `wheels` всегда `6`;
- переопределяет `go()`:  
  `"Грузовик {name} везёт груз со скоростью {speed} км/ч"`;
- добавляет свой метод `load()`:  
  `"Грузовик {name} загружается"`.

**Пример работы:**
```python
t = Transport("Поезд", 90, 8)
t.go()              # Поезд едет со скоростью 90 км/ч
t.stop()            # Поезд остановился
print(t.info())     # Поезд: 8 колёс

c = Car("Лада")
c.go()              # Машина Лада мчится со скоростью 120 км/ч
print(c.info())     # Лада: 4 колёс

b = Bike("Аист")
b.go()              # Велосипед Аист крутит педали со скоростью 20 км/ч
print(b.info())     # Аист: 2 колёс

tr = Truck("КамАЗ", 60)
tr.go()             # Грузовик КамАЗ везёт груз со скоростью 60 км/ч
tr.load()           # Грузовик КамАЗ загружается
print(tr.info())    # КамАЗ: 6 колёс

print(isinstance(c, Transport))   # True
print(isinstance(tr, Car))        # False
```

**Шаг 5.** Создай список из всех объектов (`t`, `c`, `b`, `tr`) и с помощью цикла `for` вызови у каждого метод `go()`.

**Ожидаемый вывод:**
```
Поезд едет со скоростью 90 км/ч
Машина Лада мчится со скоростью 120 км/ч
Велосипед Аист крутит педали со скоростью 20 км/ч
Грузовик КамАЗ везёт груз со скоростью 60 км/ч
```
